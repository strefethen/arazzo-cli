# Agent command discovery

The current design is the **Draft**
[agent discovery and scoped inspection plan](../../plans/current/agent-discovery-and-inspection.md),
within the [agent operability system plan](../../plans/current/agent-operability.md).
Planning authority and disposition live there.

The earlier recipe at this path mixed proposed commands with obsolete checkout
assumptions, a hand-maintained argument catalog and a single safety label per
command. It has been replaced by grammar-derived discovery, scoped inspection,
qualified identities, explicit uncertainty and effects that depend on invocation.

The proposed `agent commands`, `agent manifest`, `inspect` and schema
index/bundle surfaces are not implemented. Use the installed CLI's `--help`
and existing command schemas for available syntax. This redirect does not
change accepted ticket contracts or authorize implementation.
