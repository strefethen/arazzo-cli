# Proposed runtime dependency: existing `sha2` digest

[ac-23360](https://tkt.stevetrefethen.com/docs/ac-tickets/ac-23360) records a
bytes or undecodable response body in `trace.v2` as a descriptor with its
SHA-256 and never writes the content. That needs a SHA-256 implementation. The
recommendation is to approve `sha2 = "0.10"` as a direct `arazzo-runtime`
dependency, using the already-locked 0.10.9 artifact.
[ac-ab757](https://tkt.stevetrefethen.com/docs/ac-tickets/ac-ab757), a broader
SHA-256/Base64 qualification for replay evidence, is still open, so this log
does not reuse it and does not settle its Base64 question.
