# Decision: approved - pest

## Approval
On 2026-10-01 Steve explicitly approved promoting the existing locked `pest` and
`pest_derive` dependencies at `=2.9.1` for the parser work. This approval changes
the prior deferred disposition; the evidence below remains the September 30
review and has not been represented as a fresh security scan. Scope is direct
dependency edges at these exact pins with no new locked packages.

## Reasoning
This is a request to promote `pest` 2.9.1 and its companion proc-macro `pest_derive` 2.9.1 (same
workspace, release, and owners) from transitive to direct `[dependencies]` of `crates/arazzo-expr`.
The purpose is to generate the Arazzo 1.1 Runtime Expression and simple-condition parsers from the
specification's ABNF (approved DEC-1 in `plans/assessments/expression-parser-restructure-draft-2026-09-30.md`).
Both crates, and their whole closure (`pest_generator`, `pest_meta`, `ucd-trie`), already resolve in
`Cargo.lock` at these exact versions through `iregexp-rs` (git rev `e22a35b`, which pins `=2.9.1`).
Promotion adds dependency edges only and no locked package. Using the same default features as
`iregexp-rs` leaves feature unification unchanged.

Recommendation: **approve at `=2.9.1`**. 2.9.2 (2026-09-21) contains only a Unicode 18 table update
and a `Span::lines` fix. Moving to it would put a second pest version in the tree, or require bumping
`iregexp-rs`.
